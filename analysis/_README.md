# Pre-Analysis

This folder contains my pre-analysis code, experiments, and testing drafts.

I used these files to:

- inspect and understand the source data
- analyse dataset structure and quality
- infer schemas and datatypes
- design and test agent tools
- test LLM behaviour and prompts
- experiment with transformations
- design the data model
- test entity-resolution ideas
- investigate failures and edge cases

These files are exploratory and may contain incomplete or experimental code.

The **main, clean, and final implementation** is in the `notebooks/` folder.
